# MCP – Model Context Protocol

KI-Modelle sind gut darin, Text zu verarbeiten und zu erzeugen. Aber sie kennen nur das, was in ihrem [Kontext](../glossar#kontext) steht. Sie können keine Datei öffnen, keine Datenbank abfragen, keinen Kalender lesen – außer, Du gibst ihnen die Möglichkeit dazu.

[MCP](../glossar#mcp) ist ein offener Standard, der beschreibt, wie KI-Modelle mit externen Werkzeugen sprechen können – einheitlich, unabhängig vom Modell und vom Werkzeug.

## Zum Einstieg

Überlege, welche drei Systeme Du täglich nutzt – Dateien, Kalender, Projektmanagement. Dann frage Dich: Wie viel Zeit verbringst Du damit, Informationen aus diesen Systemen manuell in KI-Tools zu kopieren? Das ist der Bereich, den MCP adressiert.
