# Mit KI entwickeln

KI verändert das Arbeiten mit Code grundlegend – auch für Menschen ohne tiefes Programmierwissen. Aber die Grundregel bleibt: Code, den Du nicht verstehst, kannst Du nicht prüfen. Und Code, den Du nicht prüfen kannst, solltest Du nicht einsetzen.

---

## Wofür eignet sich KI – und wofür nicht?

KI ist beim Entwickeln für eine Reihe von Aufgaben gut geeignet: Code erklären, Fehler finden, Funktionen schreiben, bestehenden Code umbauen, Standardcode generieren, Dokumentation ergänzen. Gerade das Verstehen von fremdem Code – aus einem Projekt, einer Bibliothek, einem System – wird mit KI erheblich schneller.

Was KI nicht kann: die Anforderungen kennen, die Du ihr nicht gegeben hast. Wenn Du eine Funktion bestellst, ohne zu sagen, welche Randfälle behandelt werden sollen, werden sie nicht behandelt. Wenn Du nicht angibst, in welches System der Code eingebettet ist, ignoriert das Modell das System.

KI-generierter Code kann syntaktisch korrekt sein und trotzdem nicht das tun, was Du brauchst. Wer Code blind übernimmt, ohne ihn zu lesen und zu testen, baut auf einer unsicheren Grundlage.

**KI schreibt Code, der auf den Prompt passt – nicht auf die eigentliche Absicht, wenn Du die nicht präzise beschrieben hast.**

## Zum Einstieg ausprobieren

Nimm einen Code-Ausschnitt aus Deiner Arbeit – oder aus einem Projekt, das Du verstehen willst. Gib ihn in KI ein und frag: „Erkläre mir, was dieser Code tut. Geh Abschnitt für Abschnitt vor und erkläre, wozu jeder Teil da ist."

Das Ergebnis zeigt, ob Du den Code wirklich verstanden hast – oder ob die Erklärung Fragen aufwirft, die Du im nächsten Prompt stellen kannst. So funktioniert KI als Lernpartner beim Entwickeln.
